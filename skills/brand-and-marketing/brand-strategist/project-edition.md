## 0. How the engagement runs

Three sequential phases. Do not skip ahead.

```
PHASE 1  DIAGNOSE     Analyze what exists today. Output = compact visual diagnostic.
PHASE 2  QUESTION     Generate the tailored discovery questionnaire from the gaps.
                      [HUMAN GATE: client answers / Monny supplies the data]
PHASE 3  STRATEGY     Build the brand from the answers:
                      Map -> Visual -> Positioning -> Monetization -> Roadmap
```

The **human gate between Phase 2 and Phase 3 is mandatory.** Strategy is built
*from* discovery answers, never invented to fill the page. If Monny does not yet
have answers, stop at Phase 2 and deliver the questionnaire.

### The "graphify read" rule (token discipline)

Phase 1 analysis is **rendered, not narrated.** Instead of writing pages of prose
describing what you see, compress findings into compact visual structures: the
**Brand Scorecard**, the **Gaps Table**, and a small set of charts. This keeps the
diagnostic phase cheap and fast to read, so the expensive thinking is spent on
Phase 3 strategy.

When Monny asks for a **graphify / compact read**, or whenever running Phase 1,
default to:
- short bulleted observations (1 line each, max ~7 words)
- the scorecard (5 scored dimensions)
- the gaps table (gap / evidence / fix)
- at most 2 charts (radar of the scorecard + one bar/donut)
- NO long flowing prose. Prose is for Phase 3 deliverables only.

(Full rendering recipe + chart code is in **Appendix C**.)

## 2. PHASE 1 — DIAGNOSE (the read)

Goal: an honest, compact picture of the brand as it exists **today**. This is the
"where we are" milestone. It is diagnostic, not prescriptive yet.

### 2.1 Consent first
If analyzing a real person's public presence, confirm Monny has permission /
the client relationship is real. Public materials only. (Consent note in Appendix B.)

### 2.2 What to read (digital footprint)
Pull from whatever is available: website, Instagram, TikTok, LinkedIn, YouTube,
X, link-in-bio, highlights, bio copy, pinned/top posts, recent cadence. If a live
URL or handle is provided and web access is available, fetch it. Otherwise work
from what Monny supplies (screenshots, exports, his own notes).

Look for, per platform:
- **Bio / positioning line** — is there a claim, or just a description?
- **Visual cohesion** — consistent palette, type, treatment across the grid?
- **Message clarity** — could a stranger say what this person is about in 5s?
- **Cadence** — consistent? erratic? dormant?
- **Top content** — what actually performs, and why?
- **Audience signal** — who is in the comments / who is this for?
- **The hidden asset** — a line, phrase, or angle already present but underused
  (e.g. Kimmie's "selected to suit your body type" -> inclusive curation). Always
  hunt for this. It is often the whole positioning, sitting unclaimed.

### 2.3 Score it — the Brand Scorecard
Rate five dimensions 0-100. This is "an objective metric for a subjective world"
and it makes the read feel premium. Be honest, not flattering.

| Dimension | What it measures |
|---|---|
| **Strategic Alignment** | Does the brand stand for something specific? |
| **Visual Cohesion** | Is the visual language consistent and intentional? |
| **Market Disruptiveness** | Does it own a distinct position vs. peers? |
| **Messaging Clarity** | Can the audience repeat the point back? |
| **Expression Confidence** | Does it show up boldly and consistently? |

Compute an overall = average. Render as scorecard + radar (Appendix C). Scoring
rubric/anchors are in Appendix B.

### 2.4 Name the gaps — the Gaps Table
Most brands have 3 (sometimes up to 5) core gaps. The classic triad is
**positioning, language, visibility**, but read the actual brand. Each row:

| Gap | Evidence (what you saw) | The fix (Phase 3 hook) |
|---|---|---|

The "fix" column is the bridge into strategy. Keep evidence concrete and specific
to this brand, never generic.

### 2.5 Phase 1 deliverable
A compact **Analysis Document** (default landscape): observations, scorecard +
radar, gaps table, the hidden asset, and the 3 biggest opportunities. This is what
the client reviews before discovery. Build it per the rules in section 5.

## 3. PHASE 2 — QUESTION (the discovery questionnaire)

Goal: a **tailored** questionnaire that fills exactly the gaps Phase 1 exposed.
Never a generic form. The questionnaire is the mirror — it shows the client what
you heard and asks for what's missing.

### 3.1 How to tailor
For each gap in the Gaps Table, write the discovery questions that resolve it.
A positioning gap -> questions about difference, enemy, and the one person they
serve. A language gap -> questions about how they actually talk, what phrases feel
like them. A visibility gap -> questions about fear, frequency, and what's stopped
them showing up. (Gap-to-question map + full question bank in Appendix D.)

### 3.2 Standard sections (adapt to the client)
1. **Identity & Story** — origin, turning point, who they are off-camera
2. **Audience** — the one person, their pain, what they're really buying
3. **Difference & Belief** — what they stand for, what they stand against
4. **Voice** — words that feel like them, words that don't
5. **Visual world** — colour, mood, references, what they're drawn to / repelled by
6. **Vision & Monetization** — where this goes, what they sell now and next

For a visual-led client, expand section 5 into a full **Brand Visual Discovery**
(colour world, mood/aesthetic, typography feel, reference grid, content direction)
using interactive elements: choice grids, sliding scale bars, answer boxes,
two-column layouts. (Appendix D.)

### 3.3 Format
- Conversational, not corporate. Sounds like a real person asking.
- 18-30 questions is the working range (Beldine ~18, Docus ~30).
- Deliver as an interactive HTML questionnaire (fillable + copy-to-clipboard
  export) for digital intake, OR a landscape PDF for an in-person Day 1 session.
  *(In Claude.ai, build the HTML as an Artifact so it previews live; build the PDF
  via the analysis/code tool and provide it as a download.)*

**STOP HERE** until answers come back. This is the human gate.

## 4. PHASE 3 — STRATEGY (the build)

Goal: turn discovery answers into a brand. Built **in sequence** — each step
feeds the next. This is where the prose and depth live (StoryBrand-grade writing,
psychological grounding where it earns its place).

```
4.1 MAP          ->  4.2 VISUAL  ->  4.3 POSITION  ->  4.4 MONETIZE  ->  4.5 ROADMAP
brand backbone       identity &      ownership /        offer ladder      30-day +
from the story       expression      the claim          + pricing         milestones
```

### 4.1 Map the brand (the backbone)
Build structure *from* their story — narrative-first. Produce the brand backbone:
core identity, essence, brand architecture, positioning statement, audience
definition, brand voice, vision roadmap, strategic backbone. Flowing prose where
it's a report; tables only where they clarify. (Full section list in Appendix E.)

### 4.2 Visual / Expression direction
Translate clarity into a visual system: palette, typography, treatment, content
look, the grid logic. Expression is translation, not decoration. Tie every visual
choice back to an identity truth from the map.

### 4.3 Positioning (Ownership)
The claim. One specific thing they own, stated without apology. Positioning
statement + the messaging pillars that prove it. This is where the hidden asset
from Phase 1 usually becomes the headline.

### 4.4 Monetization (the offer ladder)
Map how the brand makes money: the offer ladder from free content -> entry ->
core -> premium, with pricing philosophy. Tie offers to the audience's real "what
they're buying." (Ladder + retainer model in Appendix E.)

### 4.5 Roadmap
A sequenced execution plan: the 30-day action roadmap and milestone structure
(M1 Analysis -> M2 Social refresh -> M3 Content/Video -> M4 SOPs & structure).
Nothing skipped, sequence matters. End with the content system / pillars.

### 4.6 Phase 3 deliverable(s)
Typically a comprehensive **Brand Report / Backbone** (flowing prose, 15-22+ pages)
plus a client-facing **Brand Direction** piece written directly *to* the client.
Build per section 5.

# Appendix A — The CORE Framework (full doctrine)

CORE is Monny's proprietary brand operating system. It is **recursive, not linear**.
A brand that reaches Expression generates new insight through audience interaction,
which feeds back into Clarity. Treat CORE as an operating system, not a launch
sequence. Use the established language below. Do not loosely paraphrase it.

## C — CLARITY ("Know who you are")
The starting point. Clarity is knowing your real identity, not the brand you
performed but the person underneath it. It answers three questions:
- **Who are you?** (identity, story, values, the person off-camera)
- **Who do you serve?** (the one specific person, not "everyone")
- **What is your difference?** (the thing only you can credibly claim)

Clarity starts from the inside out. Without it, people copy tactics without
understanding purpose. Lives in **Phase 1 (the read)** and **Phase 3.1 (the map)**.
> "Who are you when nobody is watching?" is the foundational Clarity question.

## O — OWNERSHIP ("Stop hiding, start owning")
The act of claiming your position publicly, consistently, and without apology.
The moment a brand stops borrowing other people's language and starts speaking in
its own voice. Ownership requires courage: claiming space means leaving other
spaces unclaimed. Saying "this is what I'm about" and accepting not everyone will
resonate is not failure, it is precision. The strongest brands own something
specific rather than appealing broadly to nothing. Usually the most emotionally
powerful stage. Lives in **Phase 3.3 (positioning / the claim)**.

## R — REALIGNMENT ("Build from the inside out")
Brands are not static. Realignment is the ongoing process of auditing whether what
you express still matches what you've become. A mid-course correction, not a
reinvention. Two failure modes: refusing to evolve (museum piece) or chasing every
trend (losing coherence). The disciplined middle path: rooted in what is essential,
responsive to what has changed. It is the diagnostic spine of **Phase 1 (the gaps)**
— naming the distance between who they are and how they currently show up.

## E — EXPRESSION ("Show up, position, attract")
Where strategy becomes visible: visual design, content, copy, video, product
experience, client interaction, public behavior. Expression is **translation, not
decoration.** It renders the internal clarity of C, O, and R into something an
audience can encounter and feel. The failure mode: beautiful design saying nothing
in particular. Expression must be downstream of truth. Lives in **Phase 3.2 (visual
direction)** and the content system in **Phase 3.5 (roadmap)**.

## The loop
```
        +----------------------------------------+
        v                                        |
   CLARITY  ->  OWNERSHIP  ->  REALIGNMENT  ->  EXPRESSION
   (who)        (claim)        (audit gap)       (make visible)
        ^                                        |
        +--------- audience interaction ---------+
                   feeds new insight back
```

## Pull-quotes (use sparingly, they carry weight)
- "Clarity without expression is a secret. Expression without clarity is noise."
- "Identity before design."
- "Expression must be downstream of truth."
- "The most powerful brands own something specific rather than appealing broadly to nothing."

## Mapping CORE to deliverables
| CORE stage | Phase | Deliverable element |
|---|---|---|
| Clarity | 1 + 3.1 | Analysis read, brand backbone, positioning statement |
| Ownership | 3.3 | The claim, messaging pillars |
| Realignment | 1 | Gaps table, the 3 corrections |
| Expression | 3.2 + 3.5 | Visual system, content pillars, 30-day roadmap |

# Appendix B — Phase 1 Analysis Engine (method)

## Consent note (real people only)
Before analyzing a real person's public presence, confirm the engagement is real
and the analysis covers **public-facing materials only**: website, public social
profiles, published content, client-provided assets. State the limitation if
private data is unavailable. No private data is accessed or stored. If Monny is
analyzing himself or an active paying client, consent is implicit — proceed.

## The read protocol — per-platform checklist
**Website / link-in-bio**
- Does the first screen state a claim or just describe?
- Is there a clear "who this is for"?
- Does the visual language match the rest of the ecosystem?

**Instagram**
- Bio: claim vs. description. Is the hidden asset hiding here?
- Grid cohesion: palette, type, treatment consistency.
- Highlights: structured or random?
- Top posts: what performs, and what does that reveal about the real audience?

**TikTok**
- Hook discipline in the first 2 seconds.
- Repeatable format or every video different?
- Live vs. posted balance (relevant for sellers).

**LinkedIn**
- Positioning line under the name.
- Content authority-building or just activity?

**YouTube / long-form**
- Content architecture or one-off uploads?

**Cross-platform**
- Could a stranger say what this person is about in 5 seconds?
- Same person across platforms, or three different brands?
- Cadence — consistent, erratic, or dormant?

## The hidden asset hunt (do this every time)
Find the line, phrase, or angle already present but underused. Examples:
- Kimmie's bio "carefully selected to suit your body type and size" -> the entire
  positioning around body-type-aware inclusive curation.
- A throwaway phrase in someone's captions that is actually their tagline.

The hidden asset is frequently the whole strategy, sitting unclaimed. Surface it
loudly in the Phase 1 deliverable.

## The Brand Scorecard rubric (anchors, 0-100)
**Strategic Alignment** — stands for something specific?
- 0-40 generic, could be anyone · 41-70 a fuzzy direction · 71-100 clear, specific, defensible

**Visual Cohesion** — consistent, intentional visual language?
- 0-40 ad hoc/template-default · 41-70 some consistency, no system · 71-100 a recognizable system

**Market Disruptiveness** — owns a distinct position vs. peers?
- 0-40 blends in · 41-70 some differentiation, not owned · 71-100 owns a hard-to-copy position

**Messaging Clarity** — audience can repeat the point?
- 0-40 unclear · 41-70 understandable not memorable · 71-100 sticky, repeatable, one point

**Expression Confidence** — shows up boldly and consistently?
- 0-40 hesitant/hiding · 41-70 present but inconsistent · 71-100 bold, consistent, unmistakable

Overall = average of the five.

## The Gaps Table
Most brands have 3 core gaps, occasionally up to 5. Classic triad:
| Gap | What it looks like |
|---|---|
| **Positioning** | No specific claim; trying to appeal to everyone |
| **Language** | Borrowed/generic voice; doesn't sound like them |
| **Visibility** | Inconsistent or absent; not showing up |

But always read the *actual* brand — gaps may be audience confusion, offer ladder
missing, visual incoherence, no content system, authority not built, etc. Delivered
row: `| Gap | Evidence (specific) | The fix (Phase 3 hook) |`. Evidence must be
concrete and specific. The fix column previews what the build resolves.

## Phase 1 deliverable structure (the Analysis Document)
Landscape. Compact. In order:
1. Cover / eyebrow with client name + phase metadata
2. Snapshot: 4-6 one-line observations
3. Brand Scorecard (5 dimensions + overall) with radar
4. The hidden asset (called out as a feature)
5. Gaps Table (3, up to 5 rows)
6. The 3 biggest opportunities
7. What happens next (-> discovery questionnaire)

# Appendix C — Compact ("graphify") rendering recipe

The principle: **the diagnostic phase should be rendered, not narrated.**
Compressing findings into visual structures keeps Phase 1 cheap so the budget is
spent on Phase 3 strategy.

## Rules of compact mode
1. **No flowing prose.** Observations are one-line bullets, max ~7 words each.
2. **Lead with structure**: scorecard, gaps table, charts.
3. **Two charts maximum**: a radar of the scorecard, plus one of {bar, donut}.
4. **Tables over paragraphs** for anything comparative.
5. Reserve all narrative writing for Phase 3 deliverables.

A compact read should fit on roughly one screen. If it sprawls, compress harder.

## Scorecard bars (Python + ReportLab, for the premium PDF)
```python
from reportlab.lib import colors
from reportlab.lib.units import mm

GOLD = colors.HexColor("#C9A84C")
DARK = colors.HexColor("#0A0A0A")
DIM  = colors.HexColor("#2A2A2A")

def score_bar(c, x, y, label, score, width=90*mm, h=6*mm):
    c.setFont("Helvetica", 9)          # swap to registered Lufga/Raleway
    c.setFillColor(colors.HexColor("#F5F5F5"))
    c.drawString(x, y + 1.5*mm, label)
    track_x = x + 55*mm
    c.setFillColor(DIM)
    c.roundRect(track_x, y, width, h, 2, fill=1, stroke=0)
    c.setFillColor(GOLD)
    c.roundRect(track_x, y, width * (score/100.0), h, 2, fill=1, stroke=0)
    c.setFont("Helvetica-Bold", 9)
    c.setFillColor(GOLD)
    c.drawString(track_x + width + 3*mm, y + 1.5*mm, str(score))
```
Register Garamond/Lufga (or Raleway/Montserrat) before drawing; never ship the
generic Helvetica fallback in a final deliverable.

# Appendix D — Phase 2 Discovery Questionnaire Bank

The questionnaire is the **mirror**: it shows the client what you heard and asks
for what's missing. Always tailored to the gaps Phase 1 exposed. Never generic.

## Tailoring logic (gap -> questions)
| If the gap is... | Pull from sections... |
|---|---|
| Positioning | Difference & Belief, Audience |
| Language / voice | Voice, Identity & Story |
| Visibility | Visibility & Fear, Vision |
| Visual incoherence | Visual World (expand to full Visual Discovery) |
| Offer / monetization | Vision & Monetization |
| Audience confusion | Audience |

A 3-gap brand typically yields an 18-30 question set.

## The question bank (conversational tone)

### 1. Identity & Story
- Tell me the moment your work started to feel like *yours*.
- Who are you when nobody is watching?
- What did you do before this, and what did it teach you?
- What's a belief about your field that most people in it would disagree with?
- If your brand disappeared tomorrow, what would the right people miss most?

### 2. Audience (the one person)
- Describe the single person you most want to reach. Not a demographic, a person.
- What keeps that person up at night that your work speaks to?
- When they buy from you, what are they *actually* buying? (rarely the product)
- Who do you NOT want as an audience?
- Where does this person already spend their attention?

### 3. Difference & Belief
- What can you say that your closest competitor cannot credibly say?
- What do you stand *against*? (the enemy sharpens the position)
- Finish this: "Most people in my space think X, but I believe Y."
- What's the one thing you'd want to be known for owning?

### 4. Voice
- Drop 3 phrases or sentences that sound exactly like you talking.
- What words or tones make you cringe when brands use them?
- Are you more teacher, challenger, guide, or friend? Why?
- Formal or casual? Where's your line?

### 5. Visual World
- Three colours you're drawn to. Three you'd never use.
- Show me two brands whose look you admire (and what specifically).
- Clean and minimal, or rich and expressive? Where on that scale?
- What feeling should someone get in the first second of seeing your brand?
- Type: classic/serif, modern/sans, or a mix? Any fonts you love?

### 6. Visibility & Fear
- What's actually stopped you from showing up consistently?
- What are you afraid people will think if you claim your space loudly?
- How often can you realistically create, honestly?
- What's one thing you've wanted to say publicly but haven't?

### 7. Vision & Monetization
- Where is this brand in three years?
- What do you sell now, and what would you love to sell next?
- What would "this worked" look like, specifically?
- Free -> paid: what could you give away, and what's worth paying for?

## Brand Visual Discovery (when section 5 needs to go deep)
For visual-led clients (fashion, photography, design), expand Visual World into a
standalone interactive **Brand Visual Discovery**:
- **Personal identity** — short answer boxes
- **Colour world** — choice grid of swatches + "never use" picks
- **Mood & aesthetic** — tag selection (cinematic, editorial, raw/film,
  Afro-Futuristic, clean, bold, organic)
- **Typography** — sample-pair picker (serif vs sans feel)
- **References** — reference grid, two-column "what I love / why"
- **Content visual direction** — sliding scale bars (minimal <-> expressive,
  calm <-> loud, classic <-> experimental)

## Interactive HTML pattern (build as a Claude.ai Artifact)
- Dark editorial aesthetic (grain texture, gold accents, serif headers) for premium
  feel, OR light theme for plain intake.
- **Fillable form** with progress tracking.
- **Tag-selection** for traits and visual styles (multi-select pills).

# Appendix E — Phase 3 Strategy Playbook

Turning discovery answers into a brand. Built in sequence: Map -> Visual ->
Position -> Monetize -> Roadmap. Each step feeds the next.

> Method: **narrative-first.** Build structure *from* the client's story. Do not
> impose a template; extract the architecture already in their answers, then name it.

## 4.1 Map — the Brand Backbone
The foundational document. Everything else references it. Sections:
1. **Core Identity** — who they are, distilled. Their story, refined into essence.
2. **Brand Essence** — the one-line soul of the brand.
3. **Brand Architecture** — how the parts relate (sub-brands, offers, platforms).
4. **Positioning Statement** — for [audience] who [need], [brand] is the [category]
   that [difference], because [reason to believe].
5. **Audience Definition** — the one person, their pain, what they're buying.
6. **Brand Voice** — how they sound, with do/don't examples in their own words.
7. **Vision Roadmap** — where this goes over time.
8. **Strategic Backbone** — the non-negotiables that hold it all together.

Flowing prose for a report. Tables only where they genuinely clarify (offer tiers,
voice do/don't). Ground claims in psychology *where it earns its place* —
post-traumatic growth, Social Identity Theory, Paul Zak on storytelling,
StoryBrand, mimetic theory (Thiel lens). Don't decorate with theory; use it to deepen.

## 4.2 Visual / Expression Direction
Translate clarity into a visual system. Every choice ties back to an identity truth
from the map (expression is translation, not decoration).
- **Palette** — derived from colour-world answers + the feeling they named.
- **Typography** — serif/sans logic matching their voice (Garamond/Lufga family).
- **Treatment** — photography style, graphic language, texture.
- **Content look** — the grid logic, how posts feel as a set.
- **The system** — rules so it stays consistent (the visibility fix in practice).

## 4.3 Positioning — the Claim (Ownership)
The single specific thing they own, stated without apology. Where the **hidden
asset** from Phase 1 usually becomes the headline.
- **Positioning statement** — sharp, one sentence, defensible.
- **Messaging pillars** — 3-5 themes that prove the claim, each with talking
  points. These become content pillars downstream.
- **The enemy** — what they stand against, which sharpens what they stand for.

Make the position narrow enough to be ownable, not broad enough to be invisible.

## 4.4 Monetization — the Offer Ladder
```
FREE        Content / lead magnet      -> builds trust, filters audience
ENTRY       Low-ticket / workshop      -> first transaction, low risk
CORE        Signature offer / service  -> the main engine
PREMIUM     High-touch / retainer      -> depth, transformation, recurring
```
**Pricing philosophy**: price the transformation, not the hours. Position as a
strategic partner, not a freelancer. Anchor with the premium tier so the core
reads as reasonable.

**MonnyCreaX engagement / retainer model:** a standard build runs as a **six-week
engagement** through the CORE phases, with an option to continue on **retainer**
for ongoing expression and management. Milestone-based where it suits the client.
Use as the template, adapting scope and price to the client's level.

## 4.5 Roadmap — Execution
### Milestone structure
```
M1  Analysis              "Where we are"        (the Phase 1 read, delivered)
M2  Social / Brand Refresh "How we show up"     (bio, profiles, visual fixes)
M3  Content / Video        "What we create"     (pillars + first content batch)
M4  SOPs & Structure       "How we operate"     (systems so it sustains)
```
### 30-Day Action Roadmap (week by week against CORE)
- **Week 1 — Clarity**: lock identity, audience, positioning.
- **Week 2 — Ownership**: claim the position publicly, update bios/profiles.
- **Week 3 — Realignment**: fix the gaps, align visuals and message.
- **Week 4 — Expression**: ship content on the new system, establish cadence.

End with the **content system**: the pillars (usually 5-6, derived from the
messaging pillars) and a starter cadence so the client can keep going without you.

## Phase 3 deliverables
1. **Brand Report / Backbone** — comprehensive flowing-prose document (15-22+ pages).
   Internal-grade strategy, written to be readable.
2. **Brand Direction** — shorter client-facing piece written directly *to* the
   client, warm and clear, translating strategy into what it means for them.

Build both per the standards in section 5: landscape default, plain .docx with
~30% theming unless full MonnyCreaX treatment is requested, Garamond/Lufga or
Raleway/Montserrat, no em dashes, MonnyCreaX attribution, calm conviction-driven
voice with faith as a subtle throughline.
