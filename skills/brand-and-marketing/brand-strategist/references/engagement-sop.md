# The Engagement SOP: Diagnose, Question, Strategy

Full phase detail, moved out of SKILL.md (2026-10-13) so it only loads for full client engagements.

## 2. PHASE 1 — DIAGNOSE (the read)

Goal: an honest, compact picture of the brand as it exists **today**. This is the
"where we are" milestone. It is diagnostic, not prescriptive yet.

### 2.1 Consent first
If analyzing a real person's public presence, confirm Monny has permission /
the client relationship is real. Public materials only. See
`references/analysis-engine.md` for the consent note.

### 2.2 What to read (digital footprint)
Pull from whatever is available: website, Instagram, TikTok, LinkedIn, YouTube,
X, link-in-bio, highlights, bio copy, pinned/top posts, recent cadence. If a live
URL or handle is provided and tools are available, fetch it. Otherwise work from
what Monny supplies (screenshots, exports, his own notes).

Look for, per platform:
- **Bio / positioning line** — is there a claim, or just a description?
- **Visual cohesion** — consistent palette, type, treatment across the grid?
- **Message clarity** — could a stranger say what this person is about in 5s?
- **Cadence** — consistent? erratic? dormant?
- **Top content** — what actually performs, and why?
- **Audience signal** — who is in the comments / who is this for?
- **The hidden asset** — a line, phrase, or angle already present but underused
  (e.g. Kimmie's "selected to suit your body type" -> inclusive curation). Always
  hunt for this. It is often the whole positioning, sitting unclaimed.

### 2.3 Score it — the Brand Scorecard
Rate five dimensions 0-100. This is "an objective metric for a subjective world"
and it makes the read feel premium. Be honest, not flattering — a real read
builds trust and justifies the intervention.

| Dimension | What it measures |
|---|---|
| **Strategic Alignment** | Does the brand stand for something specific? |
| **Visual Cohesion** | Is the visual language consistent and intentional? |
| **Market Disruptiveness** | Does it own a distinct position vs. peers? |
| **Messaging Clarity** | Can the audience repeat the point back? |
| **Expression Confidence** | Does it show up boldly and consistently? |

Compute an overall = average. Render as scorecard + radar (see graphify).

### 2.4 Name the gaps — the Gaps Table
Most brands have 3 (sometimes up to 5) core gaps. The classic triad is
**positioning, language, visibility**, but read the actual brand. Each row:

| Gap | Evidence (what you saw) | The fix (Phase 3 hook) |
|---|---|---|

The "fix" column is the bridge into strategy. Keep evidence concrete and specific
to this brand, never generic.

### 2.5 Phase 1 deliverable
A compact **Analysis Document** (default landscape): observations, scorecard +
radar, gaps table, the hidden asset, and the 3 biggest opportunities. This is what
the client reviews before discovery. Build it per the rules in SKILL.md section 4.

## 3. PHASE 2 — QUESTION (the discovery questionnaire)

Goal: a **tailored** questionnaire that fills exactly the gaps Phase 1 exposed.
Never a generic form. The questionnaire is the mirror — it shows the client what
you heard and asks for what's missing.

### 3.1 How to tailor
For each gap in the Gaps Table, write the discovery questions that resolve it.
A positioning gap -> questions about difference, enemy, and the one person they
serve. A language gap -> questions about how they actually talk, what phrases feel
like them. A visibility gap -> questions about fear, frequency, and what's stopped
them showing up.

### 3.2 Standard sections (adapt to the client)
1. **Identity & Story** — origin, turning point, who they are off-camera
2. **Audience** — the one person, their pain, what they're really buying
3. **Difference & Belief** — what they stand for, what they stand against
4. **Voice** — words that feel like them, words that don't
5. **Visual world** — colour, mood, references, what they're drawn to / repelled by
6. **Vision & Monetization** — where this goes, what they sell now and next

For a visual-led client, expand section 5 into a full **Brand Visual Discovery**
(colour world, mood/aesthetic, typography feel, reference grid, content direction)
using interactive elements: choice grids, sliding scale bars, answer boxes,
two-column layouts. See `references/questionnaire-bank.md` for the full question
bank and the interactive HTML pattern.

### 3.3 Format
- Conversational, not corporate. Sounds like a real person asking.
- 18-30 questions is the working range (Beldine ~18, Docus ~30).
- Deliver as an interactive HTML questionnaire (fillable + copy-to-clipboard
  export) for digital intake, OR a landscape PDF for an in-person Day 1 session.

**STOP HERE** until answers come back. This is the human gate.

## 4. PHASE 3 — STRATEGY (the build)

Goal: turn discovery answers into a brand. Built **in sequence** — each step
feeds the next. This is where the prose and depth live (StoryBrand-grade writing,
psychological grounding where it earns its place).

```
4.1 MAP          ->  4.2 VISUAL  ->  4.3 POSITION  ->  4.4 MONETIZE  ->  4.5 ROADMAP
brand backbone       identity &      ownership /        offer ladder      30-day +
from the story       expression      the claim          + pricing         milestones
```

### 4.1 Map the brand (the backbone)
Build structure *from* their story — this is the narrative-first method. Produce
the brand backbone: core identity, essence, brand architecture, positioning
statement, audience definition, brand voice, vision roadmap, strategic backbone.
Write it as flowing prose where it's a report; tables only where they clarify.
This is the document everything else references.

### 4.2 Visual / Expression direction
Translate clarity into a visual system: palette, typography, treatment, content
look, the grid logic. Expression is translation, not decoration. Tie every visual
choice back to an identity truth from the map. (If building actual visuals, hand
off to the `design-principles` skill — palette architecture, type pairing,
spacing, contrast — with the direction set here as the brief.)

### 4.3 Positioning (Ownership)
The claim. One specific thing they own, stated without apology. Positioning
statement + the messaging pillars that prove it. This is where the hidden asset
from Phase 1 usually becomes the headline.

### 4.4 Monetization (the offer ladder)
Map how the brand makes money: the offer ladder / growth ladder from free content
-> entry -> core -> premium, with pricing philosophy. Tie offers to the audience's
real "what they're buying." Reference the engagement/retainer model in
`references/strategy-playbook.md`.

### 4.5 Roadmap
A sequenced execution plan: the 30-day action roadmap and milestone structure
(M1 Analysis -> M2 Social refresh -> M3 Content/Video -> M4 SOPs & structure).
Nothing skipped, sequence matters. End with the content system / pillars so they
can actually keep going.

### 4.6 Phase 3 deliverable(s)
Typically a comprehensive **Brand Report / Backbone** (the flowing prose document,
can run 15-22+ pages) plus a client-facing **Brand Direction** piece written
directly *to* the client. Build per SKILL.md section 4.
